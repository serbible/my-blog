다크 모드의 핵심은 **색상을 변수로 모으는 것**입니다.

## 1. 변수로 색 정의하기

```css
:root {
  --bg: #fbfaf8;
  --fg: #1f2328;
}

:root[data-theme="dark"] {
  --bg: #16181d;
  --fg: #e4e6ea;
}
```

컴포넌트 스타일에는 색 값을 직접 쓰지 않고 `var(--bg)` 처럼 변수만 씁니다.

## 2. 시스템 설정 따르기

사용자가 직접 고르지 않았다면 `prefers-color-scheme` 으로 운영체제 설정을 따릅니다.

## 3. 깜빡임 막기

저장된 테마는 `<head>` 안에서 **동기 스크립트**로 먼저 적용합니다. 그렇지 않으면 페이지가 밝게 보였다가 어두워지는 현상이 생깁니다.

## 정리

| 항목 | 방법 |
|---|---|
| 색상 관리 | CSS 변수 |
| 기본값 | 시스템 설정 |
| 수동 선택 | `localStorage` 에 저장 |
