클로드 코드와 함께 블로그를 만들면서, 웹페이지가 **세 가지 언어의 분업**으로 이루어진다는 것을 배웠습니다. 사람에 비유하면 HTML은 뼈대, CSS는 옷차림, JavaScript는 움직임입니다.

## HTML: 구조와 의미

HTML은 페이지에 **무엇이 있는지**를 정의합니다. 제목, 문단, 링크, 이미지 같은 내용에 의미를 붙이는 역할입니다.

- `header`, `nav`, `main`, `article`, `footer` 같은 시맨틱 태그로 영역의 의미를 알려줍니다.
- 이미지의 `alt`, 버튼의 `aria-label`처럼 접근성 정보도 HTML에 담습니다.
- 이 블로그에서는 글 목록 페이지(`index.html`)와 글 상세 페이지(`post.html`)가 뼈대입니다.

## CSS: 모양과 배치

CSS는 **어떻게 보이는지**를 정합니다. 색, 글꼴, 여백, 배치가 모두 CSS의 몫입니다.

- 색상을 `:root`의 CSS 변수로 모아두면 라이트/다크 모드를 변수만 바꿔서 전환할 수 있습니다.
- 모바일 우선으로 작성하고 `min-width` 미디어 쿼리로 큰 화면을 확장합니다.
- 본문 폭을 `max-width: 720px`로 제한하는 것만으로도 글이 훨씬 읽기 편해집니다.

```css
:root {
  --bg: #fbfaf8;
  --fg: #1f2328;
}

body {
  background: var(--bg);
  color: var(--fg);
}
```

## JavaScript: 동작과 변화

JavaScript는 페이지가 **어떻게 움직이는지**를 맡습니다. 사용자의 행동에 반응하고, 데이터를 불러와 화면을 바꿉니다.

- `fetch()`로 마크다운 파일을 읽어 와서 HTML로 변환해 보여줍니다.
- 다크 모드 버튼을 누르면 `<html data-theme>` 값을 바꾸고 선택을 `localStorage`에 저장합니다.
- 주소의 `?slug=` 값을 읽어 어떤 글을 보여줄지 결정합니다.

## 한눈에 비교

| 언어 | 역할 | 이 블로그에서의 예 |
|---|---|---|
| HTML | 구조와 의미 | `index.html`, `post.html` |
| CSS | 모양과 배치 | `css/style.css`의 테마 변수 |
| JavaScript | 동작과 변화 | `markdown.js`, `app.js`, `theme.js` |

## 정리

> 내용은 HTML, 모양은 CSS, 동작은 JavaScript에 맡긴다.

세 가지가 각자 한 가지 일만 하도록 나누어 두면, 디자인을 바꿀 때 CSS만 고치면 되고 글을 추가할 때는 마크다운 파일만 만들면 됩니다. 클로드 코드에게 일을 시킬 때도 "이건 구조 문제인지, 모양 문제인지, 동작 문제인지"를 구분해서 말하면 훨씬 정확하게 전달된다는 점이 오늘의 가장 큰 배움이었습니다.
