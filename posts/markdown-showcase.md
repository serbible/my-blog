## 텍스트 꾸미기

**굵게**, *기울임*, ~~취소선~~, `인라인 코드`를 쓸 수 있습니다. [외부 링크](https://developer.mozilla.org)는 새 탭에서 열립니다.

## 코드 블록

```js
// 짧은 줄은 그대로, 긴 줄은 가로로 스크롤됩니다.
function greet(name) {
  return `안녕하세요, ${name}님! 이 줄은 아주 길게 써서 모바일 화면에서 가로 스크롤이 생기는지 확인합니다.`;
}
```
